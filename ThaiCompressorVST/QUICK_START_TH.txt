📦 ไฟล์ที่คุณได้รับ:
  ✓ SourceCode ทั้งหมด (C++)
  ✓ CMakeLists.txt (ไฟล์ build configuration)
  ✓ คู่มือการ build บน Windows
  ✓ ไฟล์ README

⚡ ขั้นตอนด่วน (5 นาที):

1️⃣  ติดตั้ง Visual Studio 2022 Community (ฟรี)
   👉 https://visualstudio.microsoft.com/downloads/
   - เลือก "Desktop development with C++"

2️⃣  ติดตั้ง JUCE Framework
   👉 https://juce.com/download/
   - แตกไฟล์ลงใน C:\JUCE

3️⃣  เตรียมไฟล์ Source Code
   - สร้าง folder: C:\ThaiCompressorVST
   - คัดลอกไฟล์ทั้งหมดจากที่นี่ลงไป

4️⃣  เปิด Command Prompt และพิมพ์:
   
   cd C:\ThaiCompressorVST
   mkdir build
   cd build
   cmake -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH=C:\JUCE ..
   cmake --build . --config Release

5️⃣  รอ Compile เสร็จ (ใช้เวลา 5-10 นาที)

6️⃣  ไฟล์ .vst3 จะอยู่ที่:
   C:\ThaiCompressorVST\build\ThaiCompressorVST_artefacts\Release\VST3\

7️⃣  คัดลอกไฟล์ .vst3 ไปที่:
   C:\Program Files\Common Files\VST3\

8️⃣  เปิด Studio One → Preferences → Plug-ins → Rescan

✅ เสร็จแล้ว! ค้นหา "Thai Compressor" ในไลบรารี่ plugin
